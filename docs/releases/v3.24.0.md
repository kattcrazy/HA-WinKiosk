**Breaking Changes**
The old single 'PowerShell command' button is gone. You now get a separate button for each PowerShell command you configured, named after that command! You'll need to update any automations that pressed the old button.

**Features**
- Camera stream modes: off, HA MQTT camera entity, or local MJPEG for NVR
- Config Buttons section: settings gear toggle and optional custom kiosk action button (MDI icon, gesture actions plus bring up keyboard)
- Multiple PowerShell commands: one Home Assistant button per command, named after that command

**Fixes**
- Custom kiosk button hidden while Settings is open
- PowerShell commands use inline name and command fields with add and remove controls
