**Features**
- Collapsible settings sections, regrouped into clearer groups (including Lockdown, MQTT connection, and MQTT entities).
- Lockdown can be turned on or off from settings. When on, the taskbar stays hidden; Exit to Windows only shows while lockdown is saved on.
- Optional Allow apps on top so other windows can cover the kiosk while lockdown is still on.
- Optional Restrict shortcuts (Win keys, Alt+Tab, Alt+F4, and similar) under Lockdown.

**Fixes**
- Taskbar is restored on startup, exit, and crash paths if a previous run left it hidden.
- Settings chrome buttons stay inset correctly when the window has a normal border (lockdown off).
